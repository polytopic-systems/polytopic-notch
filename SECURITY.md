# Security

Please report security problems privately, not in a public issue: use GitHub's "Report a vulnerability" on this
repository (Security › Advisories). We answer within a few working days.

Worth reporting: a way for an app to get into the dock without a trusted signature, to get around the block list, to
make the dock show or leak another app's content, to hide a question from the user, or to make docked apps misbehave
from outside. The dock's threat model is in [The dock](Sources/PolytopicNotch/PolytopicNotch.docc/TheDock.md#Threat-model-and-trust).
